# XSAP Studio | שאלון היכרות

אתר סטטי בעברית (RTL) עם שאלון בשלושה שלבים, לוגו XSAP בראש העמוד, ושליחת התשובות לטלגרם באמצעות פונקציית שרת של Vercel. אין צורך לרכוש שירות שליחת הודעות.

## העלאה ל-Vercel

1. צור/י מאגר GitHub חדש והעלה/י אליו את **תוכן התיקייה הזו** (או החלף/י באמצעות התוכן הזה את קוד הטופס הקיים לאחר גיבוי).
2. ב-Vercel בחר/י **Add New → Project → Import** וחבר/י את המאגר.
3. בשדה Framework Preset בחר/י **Other**. אין צורך ב-build command. תיקיית השורש היא `.`.
4. הוסף/י ב-**Project → Settings → Environment Variables** שני ערכים (Production, ואם רוצים גם Preview):
   - `TELEGRAM_BOT_TOKEN` — מפתח הבוט מ-BotFather. **אסור להכניס אותו לקובצי האתר.**
   - `TELEGRAM_CHAT_ID` — מזהה הצ'אט של שקד או קבוצה/ערוץ שבו הבוט מורשה לשלוח הודעות.
5. בצע/י **Redeploy** לאחר שמירת משתני הסביבה.
6. מלא/י את כל שלושת שלבי השאלון ושלח/י שליחת ניסיון. ודא/י שההודעה מגיעה לצ'אט הנכון.

### איך מאתרים את TELEGRAM_CHAT_ID?

שקד פותחת שיחה עם הבוט ושולחת `/start` (אם שוקלים יעד קבוצתי — מוסיפים את הבוט לקבוצה, עם הרשאות נדרשות). לאחר מכן ניתן לבדוק את `getUpdates` של ה-Telegram Bot API באופן מאובטח, בלי לפרסם או לשתף את מפתח הבוט. ה-`chat.id` בתוצאה הוא הערך המבוקש. בטלגרם הבוט לא יכול להתחיל שיחה פרטית בעצמו: שקד חייבת לכתוב לו תחילה.

### נקודות חשובות

- האתר לא חושף את מפתח הבוט בדפדפן. הפעולה `POST /api/submit` רצה בשרת Vercel.
- אפשר להשתמש במשתני הסביבה והבוט שכבר קיימים בפרויקט הנוכחי, כל עוד הערכים נשמרים תחת **אותם שמות**.
- בעת שגיאה בשליחה המשתמש יראה הודעה ולא יוצג אישור הצלחה שגוי.
- השאלה על מצב רפואי עשויה לכלול מידע אישי רגיש. בקשו רק מידע הכרחי, קבלו הסכמה מתאימה בהתאם לדין החל, והגבילו גישה לצ'אט. עדיף להימנע משליחת פירוט רפואי אישי בטלגרם; השאלון כבר מעודד לציין רק השפעה כללית על האימון, והמשך בירור רפואי יכול להיעשות בערוץ מתאים.
- קיימת בדיקת תשובות, אולם להגנה חזקה נגד ספאם מומלץ להוסיף rate limiting / CAPTCHA כשהתעבורה עולה.
- ב-Vercel ובטלגרם קיימים תנאי שימוש ומגבלות שימוש; אין התחייבות לעלות אפס בכל מצב.

## קבצים

- `index.html` — עמוד השאלון
- `style.css` — עיצוב רספונסיבי בהיר
- `app.js` — ניווט, בדיקות שדות, ושליחה
- `assets/xsap-logo.webp` — הלוגו שצורף
- `api/submit.js` — שליחת תשובות לטלגרם מצד השרת

**לא הועלה עדיין לאתר פעיל**: נדרשות הגדרת משתני הסביבה ופריסה ב-Vercel.
